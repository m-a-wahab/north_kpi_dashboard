# لوحة مؤشرات الأداء | Performance Indicators Dashboard

لوحة تحكم لعرض مؤشرات الأداء لوكالة الاستثمار في بلدية عرعر الشمالية

Performance dashboard for the Investment Agency at North Borders Municipality (Arar)

## التقنيات المستخدمة | Technologies

- React 18
- TailwindCSS (RTL Support)
- Chart.js
- React Router
- Vite

## التثبيت | Installation

```bash
npm install
```

## التشغيل | Run Development Server

```bash
npm run dev
```

## البناء | Build for Production

```bash
npm run build
```

## الميزات | Features

- ✅ واجهة عربية بالكامل مع دعم RTL
- ✅ 5 مجموعات من مؤشرات الأداء
- ✅ رسوم بيانية تفاعلية
- ✅ تصميم متجاوب
- ✅ ألوان مخصصة (#005353)

## الصفحات | Pages

1. **صفحة الفئات** - عرض المجموعات الخمسة لمؤشرات الأداء
2. **صفحة تفاصيل المجموعة** - عرض المؤشرات مع الرسوم البيانية
